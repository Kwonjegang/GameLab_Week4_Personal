# 02 · 잔광의 다리

프리미티브로 만든 턴제 퍼즐 한 스테이지입니다. 캐릭터를 직접 조작하지 않고 주 조명의 방향과 센서 앞 차폐판을 조작합니다.

## 실행

- 서버 실행 중: http://127.0.0.1:4317/afterglow/
- 서버가 꺼졌다면 이 폴더에서 `start-preview.cmd`를 실행합니다. 실행 창을 닫으면 서버도 종료됩니다.
- 외부 사이트에 배포된 주소가 아닌, 이 컴퓨터에서 사용하는 웹 프로토타입입니다.

## 조작

1. A / B / C 중 비출 다리, 센서 차폐판, 현재 조작 유지 중 하나를 선택합니다.
2. 오른쪽의 세 턴 예측과 지도 위 다음 위치를 확인합니다. 두 번째 턴부터는 조작을 그대로 유지한다고 가정한 예측입니다.
3. 한 턴 진행을 누릅니다. 캐릭터는 다음 칸에 다리가 있으면 자동으로 한 칸 이동합니다.
4. 실패해도 한 턴 되돌리기로 계속 실험할 수 있습니다.

단축키: 1/2/3 다리 선택, S 차폐판 선택, W 유지 선택, Space 진행, Z 되돌리기.

## 규칙

- A와 B는 한 턴 비추면 생성됩니다. C는 연속 세 턴이 필요합니다.
- 빛이 끊기면 두 턴에 걸쳐 잔광이 2 → 1 → 0으로 줄어듭니다. 0이 되는 턴에 그 다리에서 벗어나야 안전합니다.
- 출발점·가운데 섬·도착점은 항상 안전합니다.
- 차폐판으로 감지광을 가리면 B 다리의 현재 시간을 고정합니다. 비어 있는 B를 고정하면 다리가 생성되지 않습니다.
- C 충전은 빛을 돌릴 때 초기화됩니다. 이미 만들어진 C의 잔광은 다른 다리와 같습니다.
- 턴 순서: 장치 조작 → 충전 → 이동 → 잔광 감소 → 추락 판정.
- 빠르거나 느린 클릭 속도는 결과에 영향을 주지 않습니다.

## 기획 확인 포인트

- 캐릭터가 기다릴 위치와 다리가 사라지는 순간을 예측할 수 있는가?
- 그림자가 B 다리의 시간을 고정한다는 규칙이 화면에서 이해되는가?
- 3턴 미리보기가 수 읽기에 도움이 되는가, 정답을 너무 많이 알려주는가?
- 현재는 핵심 규칙 확인용 한 스테이지입니다. 맵 편집기나 자동 생성은 포함하지 않습니다.

## 검증

`node verify-afterglow.mjs`: 잔광 소멸·이탈·추락, C 충전 초기화, 그림자 고정 필요성, 미리보기와 실제 결과 일치, 이전 상태 보존, 도착 검증. 최단 11턴 해법이 존재하며 차폐판을 쓰지 않으면 해결할 수 없습니다.

원본 3번은 dist 루트에 유지하며 새 코드는 dist/afterglow에 있습니다. Unity Assets와 씬에는 변경이 없습니다.

브라우저에서 실제 버튼으로 추락, 복구, 힌트, 11턴 도착, 도착 후 되돌리기를 확인했습니다. 확인 시 브라우저 오류 로그는 없었습니다.
